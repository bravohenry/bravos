# Chats

Chats is the central communication hub for ZiOS, enabling users to interact with the intelligent Zi AI assistant, engage in public chat rooms, and even control their desktop environment using natural language commands. It streamlines various ZiOS functionalities into a single, intuitive interface.

## Overview

The Chats app serves as a versatile communication platform within ZiOS. Its primary function is to provide direct access to the Zi AI assistant, a powerful tool capable of understanding natural language requests to assist with coding, provide help with ZiOS features, and even manage files and applications. Beyond its AI capabilities, Chats also fosters community interaction by allowing users to join public chat rooms, connecting with other ZiOS users.

Whether you need to quickly generate a code snippet, find a specific file, launch an app, or simply chat with fellow users, Chats offers a unified and efficient way to manage your digital interactions. Its blend of AI-driven productivity and social connectivity makes it an indispensable part of the ZiOS experience, designed to enhance user workflow and collaboration.

## Features

*   **Zi AI Assistant:**
    *   **Intelligent Conversation:** Chat with Zi for general assistance, code generation, or specific help regarding ZiOS functionalities.
    *   **File & Applet Management:** Request Zi to create new HTML applets, edit existing documents, read file contents, or search the Applets Store for new tools.
    *   **System Control:** Command Zi to launch or close applications, switch between ZiOS themes, or manage playback in the [iPod](/docs/ipod) app.
    *   **Contextual Assistance:** Send a 👋 nudge to receive context-aware tips from Zi. When music is playing, Zi automatically enters "DJ Mode," offering relevant music-related interactions.
*   **Interactive Chat Rooms:**
    *   **Public Engagement:** Join various public chat rooms to connect and communicate with other ZiOS users.
    *   **AI Integration in Rooms:** Mention `@zi` within any chat room to solicit responses or assistance from the AI assistant in a public context.
*   **Voice Messaging:**
    *   **Push-to-Talk:** Utilize the Push-to-Talk feature by holding the `Space` key or tapping the microphone button to record and send voice messages effortlessly.

## User Guide

### Getting Started
To launch the Chats app, simply click its icon in the ZiOS dock or navigate to it via the [Applet Store](/docs/applet-store). Upon opening, you'll be presented with the chat interface, ready for you to interact with Zi or join a chat room.

### Key Actions
*   **To chat with Zi:** Type your message directly into the input field at the bottom of the window and press Enter.
*   **To create or edit files:** Simply ask Zi, e.g., "Zi, create a new HTML applet called 'MyWidget'" or "Zi, edit my 'Notes.txt' file."
*   **To control ZiOS apps:** Issue commands like "Zi, launch Calculator" or "Zi, switch to Dark theme."
*   **To join a chat room:** Look for the chat room sidebar (if visible) or use a menu option to browse and join available rooms.
*   **To send a voice message:** Hold down the `Space` key while speaking, then release to send. Alternatively, click the microphone icon to record.

### Tips & Shortcuts
*   **Push-to-Talk:** Hold the `Space` key for quick voice messages.
*   **AI in Chat Rooms:** Type `@zi` followed by your message in a chat room to get an AI response.
*   **Contextual Help:** Send a `👋 nudge` message to Zi for helpful tips based on your current ZiOS activity.
*   **DJ Mode:** If the Music app is playing, Zi will automatically offer music-related interactions.

## Technical Details

### Window Configuration
*   **Default size:** 560×360px
*   **Minimum size:** 300×320px

### Component Architecture
The app consists of 7 component file(s):

*   `src/apps/chats/components/ChatMessages.tsx`
*   `src/apps/chats/components/TokenStatus.tsx`
*   `src/apps/chats/components/CreateRoomDialog.tsx`
*   `src/apps/chats/components/ChatRoomSidebar.tsx`
*   `src/apps/chats/components/ChatsMenuBar.tsx`
*   `src/apps/chats/components/ChatInput.tsx`
*   `src/apps/chats/components/ChatsAppComponent.tsx`

### Hooks & Utilities
**Custom Hooks:**
*   `src/apps/chats/hooks/useTokenRefresh.ts`
*   `src/apps/chats/hooks/useZiChat.ts`
*   `src/apps/chats/hooks/useChatRoom.ts`
*   `src/apps/chats/hooks/useAiChat.ts`

### State Management
The Chats app leverages a Zustand store, specifically `useChatsStore`, for managing global application state related to chat messages, room information, and other UI states. Local component state is also utilized where appropriate for temporary UI interactions.
